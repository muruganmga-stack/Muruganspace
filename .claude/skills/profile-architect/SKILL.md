# Play 02: Profile architect

Use with the `linkedin-profile-optimizer` and `voice-and-tone` skills if available.

## Inputs
- Current profile text pasted into `department/inputs/profile/current.md`
- `icp.md`, `offer.md`, `proof-bank.md`

## The 7-second test
A Hot prospect lands from a comment. In 7 seconds they must know:
1. **Who you help** (their title or company type is in the headline)
2. **What changes** (an outcome, ideally with a number)
3. **Why believe you** (one proof point above the fold)
4. **What to do next** (Featured slot 1 = the Pipeline Teardown or a lead magnet)

## Deliverables (write to `department/outputs/<week>/profile.md`)
- 3 headline options, max 220 chars, each with who + outcome + how
- About section: hook line, the problem, how Murugan fixes it (3 bullets),
  proof, who it's not for, clear CTA. 1,200 to 1,800 chars.
- Featured: 3 slots with title + 1-line description for each
- Banner copy: max 8 words + sub-line, in navy/cream palette
- Experience: rewrite the current role's description to support the brand
  without conflicting with the employer
- Creator mode topics: 5 hashtags matched to the pillars

Score the current profile and the new one on the 4 tests (0 to 5 each).
