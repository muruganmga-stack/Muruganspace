# Play 08: Follow-up runner

## Steps
1. Query Notion Touches for status `Sent` with no reply and next due date
   within 3 days. Query Prospects in stage `Conversation`.
2. For each, read the full touch history first. List the sentences already
   used so none repeat.
3. Classify any new reply using the classes in `message-rules.md`.
4. Draft the next touch for the right class. Interested → offer the
   Pipeline Teardown with the booking link from `offer.md`.
5. After touch 3 with no reply, set stage to `Nurture` and next check-in to
   30 days out. No touch 4.
6. Not now → set next touch date to the month they named.

## Output
A checklist for Murugan: person, class, drafted message, why this message.
Update Notion stage and dates.
