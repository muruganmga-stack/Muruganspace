# Play 09: Learning loop

## Pull the numbers (Notion)
- Content: per post, impressions, comments, ICP comments (fit ≥ 25),
  profile views, prospects created, conversations opened, calls booked
- Prospects: count by tier, tier changes, source post
- Touches: sent, replies, reply rate by touch number and entry type

## Attribute
For every call booked or Interested reply, trace back: which post, which
signal, which opener. One row per opportunity in `review.md`.

## Ask 5 questions
1. Which post produced the most ICP comments per 1,000 impressions?
2. Which hook pattern beat the others?
3. Which opener type got the highest reply rate? (need 10+ sends to judge)
4. Who engaged that we didn't expect? Should `icp.md` change?
5. Where did the funnel leak worst: attention, signal, reply, or booking?

## Output
`department/outputs/<week>/review.md` with a scorecard vs targets in
`CLAUDE.md` and exactly **3 changes** for next week: one for content, one
for outreach, one for targeting. Not five. Three.
